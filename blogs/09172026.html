project516's iOS Sideloading Overview

Welcome to the world of iOS sideloading! This will be mainly an overview article. I will be linking to documentation pages, if you want to read more!

Note: I will only be covering iOS sideloading. This applies to iPadOS as well, but not to Android devices. If you use an Android device (any phone running on Android or Android - based), it is much easier to sideload apps (for now. See Keep Android Open for more info).

So, to begin, I will explain what sideloading is. Sideloading is the practice of installing software or apps on a device from sources outside the official app store. Easy, right? Except big companies, like Apple and Google, don't want you to do that. Why? They say it's to keep users safe by preventing malware, but it's really to increase their revenue.

Also, just to be clear: Sideloading is NOT jailbreaking. Jailbreaking can be used to sideload apps, but it is not needed for sideloading.

So in my opinion, Sidestore is the best option. Why? Sidestore is a fork of Altstore (more on that later), with a lot of new features. While it is kinda hard to set up (all of the tools are), once it is set up, you don't need to think about it. It is truly a set - and - forget option.

I have been using Sidestore for almost a year, and I have been happy with it. Sidestore is best paired with Live Container (more on that later).

One feature I like about Sidestore is the on device refresh. If you don't know, Apple forces you to sign you apps every seven days, why? Nobody knows (common theme with Apples policies). On - device - refresh lets you refresh your apps without a computer. The Sidestore team has gotten cellular refreshing to work (experimental), so you don't need to be connected to WiFi.

Sidestore and the components are probably one of the biggest and most actively developed solutions for sideloading.

So a less popular sideloading option is Altstore. Altstore doesn't have too much active development, and has their development builds locked behind their Patreon. They are also focusing on Altstore PAL, a version of Altstore for the PAL region. I have not used Altstore PAL, but if you are in the region, you should definitely check it out!

I would not recommend Altstore. Sidestore is a much better option. While recently, Altstore has implemented on device refresh as well, Sidestore still has way more features.

Another option is Sideloadly. I originally used Sideloadly, but I quickly moved to Altstore (before moving to Sidestore). Sideloadly is not open source either. I didn't like the UI when I used it, and I could not get the wifi refresh to work. Its alright for sideloading a single app, but it's not good for keeping the app updated. Also, it doesn't support Linux, so I can't really use it.

iLoader is tool you can use to sideload apps on your iOS device, similarly to sideloadly, but it is open source, and supports Linux. It is also much newer, and used to sideload Sidestore initially, so it has an active community around it.

I mentioned this before, but Live Container is a great tool to use while sideloading. Apple limits you to three apps at a time, but Live Container is a sandbox for running apps, so you can install as many apps as you want with it.

So to sum it up, Sidestore is the best option for sideloading apps on your iOS device, because it is modern, has a great community, and is easy to use once you set it up.
