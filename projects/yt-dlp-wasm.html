yt-dlp-wasm

yt-dlp running in the browser and Node.js with WebAssembly.

Python WebAssembly Pyodide npm AGPL-3.0

Runs yt-dlp on Pyodide, so no server is needed. The npm package installs a yt-dlp-wasm command that takes the same arguments as yt-dlp.
