ffmpeg-dnf

FFmpeg master in your dnf install, rebuilt every week.

RPM Fedora DNF MIT

Fedora and RPM Fusion ship FFmpeg releases, not master. This repo adds a dnf repository that builds RPMs from FFmpeg's master branch on a weekly schedule, so whatever landed this week is one dnf upgrade away.

Drop the repo file into /etc/yum.repos.d, run dnf makecache, and dnf install ffmpeg picks up the weekly build. Removing it is deleting that file and pointing dnf back at fedora and updates.
