dart-packages

The Dart and Flutter packages I keep needing to write twice.

Dart Flutter AGPL-3.0

Four are pure Dart API clients: tba_client for The Blue Alliance, statbotics_client, match13_client and firestore_client, which covers Firebase Auth and Firestore over REST. Three wrap Apple platform views for Flutter on iOS and macOS: liquid_glass, apple_ai for on-device Foundation Models, and apple_web_auth for ASWebAuthenticationSession.

Each package has its own pubspec, tests and version tag, and you depend on one by git ref. CI runs format, analyze and test across all of them, plus iOS and macOS builds of the plugin example apps.
