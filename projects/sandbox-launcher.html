sandbox-launcher

Every Minecraft instance in its own container.

Java JavaFX Docker AGPL-3.0

Each instance gets a container with the Java version that Minecraft release wants, so old versions and current mod loaders sit side by side without one instance's files or mods reaching another. The images are pulled from GHCR on first launch, so there is no Docker setup to do by hand.

It handles Fabric, Forge and NeoForge, proxies 1.5 and below through Betacraft, and gives every instance its own name, icon, username and console window with a kill button for when one hangs. Linux only, since it needs an X11 display server.
