hollywood-docker

One docker run and your terminal splits into a hacker movie scene.

Dockerfile GHCR MIT

hollywood is a Debian package that fills a console with the stereotype: a split terminal running system monitors in a movie hacker scene. The image runs it on start, so docker run is the whole install.

It needs a TTY. Without the -t flag you get 'the input device is not a TTY', because hollywood's interface draws to a pseudo-terminal. Press q to stop it.
